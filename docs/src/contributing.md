# Contributing

This page points you to the guides for changing oneloop itself.

oneloop is open source under the MIT license, and bug reports and pull requests are welcome.
The contributor guides live in the repository, next to the code they describe:

| Guide | Read it for |
| --- | --- |
| [CONTRIBUTING.md](https://github.com/code19m/oneloop/blob/main/CONTRIBUTING.md) | Setting up, running the app locally, the checks to run, tests, pull requests, writing docs and releasing |
| [ARCHITECTURE.md](https://github.com/code19m/oneloop/blob/main/ARCHITECTURE.md) | A map of the code and the rules it must keep |
| [SECURITY.md](https://github.com/code19m/oneloop/blob/main/SECURITY.md) | Reporting a vulnerability privately |

To suggest an improvement to this site, use the edit link at the top of any page.
Found a bug or have an idea? [Open an issue](https://github.com/code19m/oneloop/issues).
